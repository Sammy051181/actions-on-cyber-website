Today’s SMB cyber lookout: malicious marketplace extensions + Microsoft update disruption

What small and medium-sized businesses should look out for today.

High Saturday 14 November 2026, 20:42 UK time
Today’s look-out: Supplier/marketplace incident scams and business disruption from software updates

What to look out for today

1) Supplier/marketplace risk: Cursor has confirmed a security breach that enabled a malicious “Claude Code” extension to be distributed via its marketplace (after credentials were stolen from an AI infrastructure provider).

2) IT disruption risk: Microsoft has reported that November 2026 updates may cause printing issues (especially complex formatted documents) and has also confirmed Windows activation/licensing failures after the updates.

Why this matters to smaller businesses

  • Malicious extensions can act like an “inside helper” on staff devices, potentially accessing data, tokens, code, or browser sessions depending on what the tool integrates with.
  • Marketplace trust can be abused: staff may install updates/extensions because they appear “official” and come from a known marketplace.
  • Update side-effects can stop work: if printing or licensing breaks, teams lose time, support queues spike, and attackers often take advantage with “helpdesk” impersonation scams.

Warning signs

  • Staff report a new or updated extension/tool that they didn’t request, or prompts to “re-authorise” access unexpectedly.
  • Unexpected consent screens asking to access code repositories, email, files, contacts, or organisational data.
  • Devices suddenly running slowly after installing a new dev/AI tool, or security tools flagging new browser/editor add-ons.
  • After Windows updates: users see activation/licensing errors, repeated “activate Windows” prompts, or apps claiming they’re unlicensed.
  • Printing suddenly fails for only certain documents (complex formatting) right after updates.
  • Emails/calls claiming to be Microsoft/IT support offering to “fix activation” or “restore printing” if you install something or share credentials.

How attackers may exploit the situation

  • Trojanised extensions distributed via a trusted marketplace can be used to harvest credentials/tokens or manipulate what users see/do in their tools.
  • Follow-on phishing: criminals may send “security notice” emails referencing the Cursor incident to push staff to install a fake “cleanup tool” or re-login to a lookalike page.
  • Disruption-driven scams: printing/licensing problems create a perfect excuse for fake IT support outreach and urgent payment requests for “licence renewals”.

What to do today

  • Freeze non-essential extension installs/updates for dev/AI tools until you confirm what’s approved in your business.
  • Inventory and review: list which staff machines have Cursor (and any related extensions) installed and check for unexpected recent changes.
  • Reinforce the rule: staff must not install “fix tools” from emails/chats/calls. All support goes via your normal IT route.
  • Prepare for disruption: if you rely on printing (invoices, labels, care plans, school admin), agree a workaround plan for the weekend/next working day (PDF alternative, alternative printer, print-from-another-device process).
  • Licensing sanity-check: if Windows activation issues appear, treat as an IT incident (not an individual user problem) and track impacted devices.

Ask your IT provider

  • Do we have controls over extension installation (allow-listing / admin approval) for key tools and browsers?
  • Can you provide a report of newly installed or updated extensions across company devices in the last 7–14 days?
  • What is our standard response if a third-party marketplace distributes a malicious add-on (containment, removal, credential/token reset)?
  • Are we monitoring for unusual sign-ins to code, email, file storage and admin consoles following add-on installs?
  • What’s the plan for Microsoft update side-effects (printing/licensing): rollback approach, escalation route, user comms template?

Patch watch - only one short paragraph, and only if relevant

Be aware that Microsoft’s November updates are linked with printing problems and Windows activation/licensing failures in some environments. If you’re due to apply updates, make sure IT has a rollback/contingency plan and that business-critical printing and licensing-dependent apps are tested before broad rollout.

One action today

Send a same-day internal note: “Do not install or update any new extensions/tools from marketplaces unless IT has approved it; report any activation/licensing pop-ups or printing failures immediately via the usual IT channel.”
