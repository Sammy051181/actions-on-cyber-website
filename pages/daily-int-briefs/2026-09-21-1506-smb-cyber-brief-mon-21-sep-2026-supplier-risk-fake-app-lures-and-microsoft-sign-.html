SMB Cyber Brief (Mon 21 Sep 2026): Supplier risk, fake app lures, and Microsoft sign-in/backup disruption

What small and medium-sized businesses should look out for today.

High Monday 21 September 2026, 15:06 UK time
Today’s look-out: Supplier compromise + fake software update lures + Microsoft identity/backup disruption

What to look out for today

  • IT provider / MSP supply-chain risk: a smaller IT services firm was reportedly compromised and used as a stepping-stone for further access. If you outsource IT, treat unusual admin activity as a potential supplier-origin incident.
  • “Fix it now” / ClickFix-style lures: campaigns are pushing a remote access trojan by pretending to be installers or updates for familiar workplace tools (e.g., Teams/Zoom/Spotify-branded downloads).
  • Microsoft identity change on the horizon: Microsoft is reminding admins to move Entra ID users to phishing-resistant sign-in methods ahead of SMS first-factor sign-in retirement (Feb 2027). This is a planning and comms item now, not a last-minute scramble later.

Why this matters to smaller businesses

  • Supplier compromise hits SMEs hardest: if your IT provider is breached, attackers may inherit trusted remote access, admin credentials, or support tooling—often without triggering the same scrutiny as a direct attack.
  • Fake app downloads are “everyday believable”: staff are used to installing meeting tools and “updates”, so a convincing prompt can lead to hands-on-keyboard compromise quickly.
  • Identity and access disruption is a business risk: if you rely on Microsoft 365/Entra ID for email and files, unplanned authentication changes can lock users out or increase helpdesk load at the worst time.

Warning signs

  • Emails/DMs urging staff to “run this fix”, “verify your device”, or “install the latest Teams/Zoom Workplace update”, especially with odd links or rushed language.
  • Staff report seeing pop-ups or web pages claiming their browser/device is broken and providing steps to “click and paste” or download a tool to fix it.
  • Unexpected MFA prompts, password reset emails, or new device sign-in alerts for Microsoft 365.
  • New or unusual remote support sessions, admin logins, or configuration changes that your team didn’t request (especially outside business hours).

How attackers may exploit the situation

  • Supplier route: attackers compromise a small IT services provider and reuse its access to reach client environments, blending in as legitimate support activity.
  • RAT delivery via “productivity app” branding: users are tricked into installing a trojan disguised as common software; once installed, criminals can harvest data, move laterally, and deploy further tooling.
  • Account takeover: if sign-in methods are weak (or users are trained to accept prompts), attackers may push through access to mailboxes and files, then use that access for invoice fraud or internal phishing.

What to do today

  • Send a 2-minute staff note: “No one should install meeting apps/updates from links in emails or chats. Use Company Portal / approved app store / IT-managed install only. Report ‘fix now’ pop-ups.”
  • Lock down installs where you can: restrict local admin rights; ensure software installs are managed/approved (even if that’s a simple documented process for small teams).
  • Review supplier access: confirm which third parties have remote access, how it’s authenticated, and whether access is time-bound and logged.
  • Plan Entra ID move away from SMS first-factor: identify users still relying on SMS first-factor sign-in and set a timeline to move them to phishing-resistant methods (e.g., passkeys) with clear user comms and support.

Ask your IT provider

  • Which remote access tools and admin accounts do you use in our environment, and how do you protect them (MFA, device controls, logging)?
  • Do you have a process to detect and alert us to suspicious activity that could originate from your own tools or accounts?
  • How are end-user installs controlled (local admin rights, application allow/deny rules, approved install sources)?
  • What is our current position on Entra ID sign-in methods—are any users relying on SMS first-factor, and what is the migration plan ahead of Feb 2027?

Patch watch - only one short paragraph, and only if relevant

Microsoft has warned that Windows File History backups may stop working on some systems after September 2026 security updates. If you rely on File History, ask IT to verify that backups are still running and that restores work; don’t assume “backup is fine” until it’s tested.

One action today

Send a company-wide note today: staff must not install “Teams/Zoom/Spotify updates” from email/chat links—only via approved sources—and must report any “fix now” pop-ups or unexpected MFA prompts immediately.
